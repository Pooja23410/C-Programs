# Student Record Manager in C

A simple menu-driven student record management system implemented in C.

## Features

- Add Student
- Display Students
- Search Student
- Update Student
- Delete Student
- Exit

## C Concepts Used

- Structures
- Arrays
- Loops
- Conditional Statements
- Strings
- CRUD Operations
