# Embedded Device Configuration Manager

A menu-driven C program that simulates managing configuration settings for multiple embedded devices.

## Features

* Add device configurations
* Modify existing configurations
* Display all device configurations
* Validate configuration parameters
* Reset/remove a device configuration
* Store multiple device configurations using structures and arrays
* Uses status flags for configuration validation

## Configuration Parameters

Each device stores:

* Device ID
* Firmware Version
* Sampling Rate
* Operating Mode
* Temperature Limit
* Voltage Limit
* Communication Mode
* Status Flags

## C Concepts Used

* Structures
* Arrays
* Pointers
* Enumerations (`enum`)
* Functions
* Strings
* Bit manipulation
* Menu-driven programming
* Input validation

## How to Run

1. Open the C file in any online C compiler.
2. Compile and run the program.
3. Use the menu to add, modify, display, validate, or reset device configurations.

## Project Type

**Console-based C simulation**

This project does not use actual embedded hardware. It simulates device configuration management using C programming concepts commonly used in embedded software.
